# 🚗 Cars24 Used Car Market Analysis

## 📊 End-to-End Data Analytics & Business Intelligence Project

An end-to-end data analytics project that collects used-car listing data from Cars24, processes and analyzes the data using Python, creates visualizations, and presents the results through an interactive Power BI dashboard.

---

## 🎯 Project Overview

The used-car market contains a wide range of vehicles with different brands, prices, manufacturing years, fuel types, transmission types, mileage levels and locations.

This project analyzes a sample of Cars24 used-car listings to understand:

- Vehicle inventory by brand
- Used-car pricing patterns
- Fuel type distribution
- Transmission distribution
- Vehicle age
- Mileage patterns
- Relationship between mileage and price
- Location-level inventory
