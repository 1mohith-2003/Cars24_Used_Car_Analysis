# Cars24 Used Car Market Analysis

## Slide 1 — Title

Cars24 Used Car Market Analysis

Data Analytics & Business Intelligence Project

Tools:
Python | Selenium | Pandas | NumPy | Power BI


## Slide 2 — Project Overview

This project analyzes used-car listings collected from Cars24.

The project follows an end-to-end data analytics workflow:

Web Scraping
→ Data Extraction
→ Data Cleaning
→ EDA
→ Visualization
→ Power BI Dashboard


## Slide 3 — Business Problem

Used-car listings contain multiple attributes such as:

- Brand
- Model
- Price
- Manufacturing Year
- Fuel Type
- Transmission
- Mileage
- Location

The objective is to understand pricing, inventory and vehicle characteristics within the collected Cars24 sample.


## Slide 4 — Data Collection

Technology used:

- Python
- Selenium
- HTML
- Regular Expressions

Cars24 used-car webpage data was captured and stored as HTML.

Listing records were extracted into a structured CSV dataset.


## Slide 5 — Data Cleaning

Python and Pandas were used for data preparation.

Cleaning activities:

- Remove empty columns
- Clean text fields
- Convert numerical columns
- Validate prices
- Validate mileage
- Validate vehicle years
- Remove duplicate listings
- Create cleaned dataset
